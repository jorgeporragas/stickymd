# Choice

One question with a few answers: a row of `Toggle`s with `role="radio"` inside a `radiogroup`, each captioned underneath. Takes `options` (`value`, `label`), `value`, `label`, `onChange`.

The captions are what make it a choice. A row of identical discs with no captions is a puzzle, because which one is which cannot be inferred from position. Extracted from the theme row when the launch choice became its second use (SMD-104).
